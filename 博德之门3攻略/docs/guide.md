## 一、快速上手

《博德之门3》是 CRPG 巅峰之作，以 D&D 5e 规则为基础，强调 **策略战斗 + 分支叙事**。

### 1.1 开局建议
- 优先理解 **动作/附赠动作/反应** 的资源体系；
- 第一场战斗善用 **高地优势**（+2 命中）；
- 对话选项会影响剧情走向，存档多分支。


## 二、核心玩法

### 2.1 战斗系统
- **法术位**：长休恢复，谨慎分配；
- **环境互动**：油桶、悬崖、陷阱都可利用。

### 2.2 队伍搭配
| 角色 | 定位 |
|------|------|
| 战士/野蛮人 | 前排坦克 |
| 法师/术士 | 远程爆发 |
| 牧师/德鲁伊 | 治疗辅助 |
| 游荡者 | 偷袭/开锁 |



## 三、进阶技巧

- **先攻优势**：潜行先手 + 控制法术可秒杀关键敌人；
- **长休时机**：剧情节点前记得长休，触发同伴剧情；
- **检定加成**：装备/药水堆叠属性，提高关键检定成功率。
